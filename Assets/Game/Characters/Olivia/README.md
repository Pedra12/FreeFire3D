# Olivia character asset

This is the only approved playable character in the Unity project.

## Canonical model

- Model: `Olivia.glb`
- Rig report: `OliviaRigReport.json`
- Humanoid Avatar asset: `OliviaAvatar.asset` (generated by Unity Editor)
- Animator Controller: `Olivia.controller` (generated from the selected Quaternius clips)
- Character source archive: `SourceArchives/olivia-free-fire.zip`

The source model contained seven meshes but no armature, skin or animation clips. The preparation pipeline created one 22-bone humanoid skeleton, assigned normalized skin weights, tested pose deformation, exported one skinned GLB and re-imported it to verify that the skin survived.

## Animation source

The only selected animation donor is Quaternius Universal Animation Library Standard, CC0 1.0 Universal:
`Assets/Game/Animations/Quaternius/UAL1_Standard.fbx`.

Unity's native FBX importer is configured to import the donor as a Humanoid rig. The import postprocessor strips its renderer components; the donor is never instantiated as a playable character. Its clips are intended to retarget through Unity's Humanoid system.

The generated controller uses in-place idle, walk, jog, sprint, crouch and jump clips. Weapon aim, fire and reload states will be connected when the weapon system is implemented.

## Validation status

Blender verified Olivia's skinning, pose deformation and GLB round-trip. Unity Editor has not yet run, so the Humanoid Avatar, FBX clip import, animation retargeting, final pose quality and Android performance remain unverified.

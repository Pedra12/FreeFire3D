# Clocktower map asset

This is the only approved playable map destination for the first Unity vertical slice.

Import one inspected Clocktower map from `free-fire-clocktower-3d-model-by-rs-ratul.zip`. Do not import other map archives, alternate map versions or duplicate scenes. Validate orientation, scale, materials, collision and walkable interiors before the map becomes the match scene. If the map is replaced, remove the previous version in the same change.

No map model has been imported yet. This folder is intentionally reserved until the archive can be inspected safely.
